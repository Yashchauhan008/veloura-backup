## ✨ Core Functionality & Tech Stack

This server provides a complete RESTful API with secure endpoints.

- **User Management:** Secure user registration and login using **bcrypt** for password hashing and **JSON Web Tokens (JWT)** for session management.
- **API Endpoints:** A full suite of CRUD endpoints built with **Express.js** to interact with the frontend.
- **Data Persistence:** **MongoDB** was used as our database, with **Mongoose** schemas ensuring data consistency under pressure.
- **Connectivity:** **CORS** middleware was configured to allow seamless communication with our React client.

| Category       | Technology Used      |

## 🚀 How to Run This Project

1.  **Clone the repo:** `git clone https://github.com/your-username/veloura-server.git`
2.  **Navigate into the directory:** `cd veloura-server`
3.  **Install packages:** `npm install`
4.  **Create a `.env` file** with `PORT`, `MONGO_URI`, and `JWT_SECRET`.
5.  **Launch the server:** `npm start`
