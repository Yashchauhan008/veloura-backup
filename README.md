## 🚀 Getting Started (Local Development)

### Prerequisites
- Node.js (v16 or higher)
- npm / yarn
- A running instance of the [Veloura-server](https://github.com/your-username/veloura-server )

### Installation & Setup
1.  **Clone the repository:**
    ```sh
    git clone https://github.com/your-username/veloura-client.git
    cd veloura-client
    ```

2.  **Install dependencies:**
    ```sh
    npm install
    ```

3.  **Set up environment variables:**
    Create a `.env` file in the root directory and add the backend API URL:
    ```env
    VITE_API_BASE_URL=http://localhost:8080/api
    ```

4.  **Run the development server:**
    ```sh
    npm run dev
    ```
    The app will be available at `http://localhost:5173` (or another port specified by Vite ).
